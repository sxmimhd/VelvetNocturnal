# About

**Velvet Nocturnal** is a 2D psychological horror adventure focused on exploration, dialogue, environmental storytelling, and atmosphere.

After receiving a mysterious invitation from a forgotten family, **Lumy** and **Carlos** find themselves trapped inside the cursed **Nocturnal Mansion**.

As they search for a way out, they uncover fragmented memories, evade terrifying Keepers, solve environmental puzzles, and piece together the truth hidden within the crimson Velvets.

Some secrets have remained buried for centuries...

...and not all of them should awaken.
